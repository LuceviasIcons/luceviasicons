# Changelog

Icons land in batches, several times a week, while versions are bumped only on a
release — so this log is kept by date rather than by version. The catalog marks
the newest batch with a green dot; this is the same information, written down.

The set is still growing, and coverage is uneven by design: it is drawn roughly
alphabetically, so early letters are dense and later ones are thin. If an icon
you need is missing, [ask for it](CONTRIBUTING.md#requesting-an-icon).

### How the "new" marks work

An icon carries the day it appeared and the day its markup last changed. The
catalog compares those against the freshest date in the set, so only the latest
batch is ever marked — a new batch puts out the previous one by itself, with no
release and no manual action.

This used to key off the package version, which does not work: versions are
bumped on a release, batches arrive several times a week, and by the fourth
batch 349 of 686 icons were marked "new" — half the catalog, which tells a
visitor nothing.
