# Icon Library

Каталог SVG-иконок в духе phosphoricons.com. Vite + React 19 + TS + Tailwind v4.

## Запуск

```bash
npm run dev      # dev-сервер
npm run build    # tsc -b && vite build
npx tsc --noEmit # только типы
```

## Архитектура

- `src/icons/types.ts` — `IconDef`, `Weight`, `IconStatus`, `STATUS_MARK`, `VIEW_BOX` (0 0 256 256 — дефолт). У иконки может быть свой `viewBox`: он берётся из исходного файла, иначе 24×24-иконки отрисуются крошечными.
- `src/icons/load.ts` — сборка иконок из `src/icons/svg/` через `import.meta.glob`. Имя файла = название иконки как есть, без Title Case.
- `src/icons/status.ts` — маркировка «новая / обновлена»: снимок папки (имя → хеш разметки) в localStorage сравнивается с текущим. База пишется только по кнопке «Отметить просмотренным».
- `src/icons/data.ts` — источник иконок. Сейчас 20 плейсхолдеров-квадратов, генерируются из `SEEDS` + `placeholder()`. **Здесь заменять на реальные SVG.**
- `src/icons/search.ts` — поиск на Fuse.js, терпит опечатки (`align-btm` → `align-bottom`). Индекс кэшируется по ссылке на массив иконок.
- `src/icons/render.ts` — вся сериализация и экспорт: `toSvgString`, `toPrettySvg`, `toJsx`, `viewBoxOf`, `downloadSvg`, `downloadPng`.
- `src/icons/snippets.ts` — вкладки платформ (React/Web/Vue/Flutter/Elm/Swift). Каждая цель — объект с `install` и `build`; сниппет короткий, вида `<BoundingBox size={32} />`, потому что предполагает подключённый пакет. Добавить платформу = дописать элемент в `TARGETS`.
- `src/components/` — `Icon` (рендер), `IconGrid` (+ `StatusDot`), `Controls` (липкая панель между hero и сеткой: поиск/вес/размер), `DetailPanel` (плавающая панель внизу), `Hero` (схема труб + переключатель темы узлом).

Категорий нет — фильтрация только поиском. Выбора цвета нет. Отдельной шапки нет: имя продукта и переключатель темы живут в hero.

Раскладка: hero → липкая `Controls` (`sticky top-0`) → сетка; `DetailPanel` плавает внизу поверх всего (`fixed bottom-0`, z-40). Ячейка сетки фиксирована в 132px: слайдер размера меняет иконку и код, но не перекомпоновывает сетку.

Веса выбираются через Radix DropdownMenu с `modal={false}` — иначе Radix вешает `overflow:hidden` на body и страница перестаёт скроллиться.
- `src/hooks/useCopy.ts` — копирование в буфер с фолбэком для http.

Состояние (вес, размер, цвет, выбранная иконка, тема) живёт в `App.tsx` и передаётся вниз пропсами. Отдельного стора нет и он не нужен.

## Пайплайн

Источник истины — файлы в `src/icons/svg/`. Из них растёт и сайт, и npm-пакет.

```
src/icons/svg/*.svg
  ├─ сайт    → npm run build → GitHub Pages (.github/workflows/deploy.yml, пуш в main)
  └─ пакет   → npm run pkg:build → npm (.github/workflows/publish.yml, тег v*)
```

- `scripts/build-package.mjs` — генерирует React-компоненты в `packages/icons/src` (в гит не коммитятся, см. .gitignore). Каждый компонент помечен `/* #__PURE__ */` — без этого tree-shaking ломается и импорт одной иконки тянет весь пакет (185 КБ против 9 КБ).
- Публикация: `git tag v0.2.0 && git push --tags`. Версия берётся из тега. Нужен секрет `NPM_TOKEN`.
- `vite.config.ts` задаёт `base` для Pages — при другом имени репозитория переопределить через `BASE_PATH`.

## Как добавлять иконки

В `src/icons/data.ts` заменить `placeholder()` на объект `variants` с реальной разметкой путей (без обёртки `<svg>`, viewBox 0 0 256 256). Обязателен ключ `regular` — остальные веса откатываются на него. Остальной код менять не требуется.

## Инструменты

```bash
npm run icons:optimize   # SVGO по src/icons/svg (правит файлы на месте)
npm run a11y             # axe-core по живой странице; нужен запущенный dev
```

`npm run a11y` падает при нарушениях serious/critical и проверяет две сцены: сетку и открытую деталку. Держать на нуле.

Зависимости UI: Radix (тултипы, меню), Fuse.js (поиск). Анимации — на CSS, анимационных библиотек нет и не нужно.

## Правила работы с кодом

Перед созданием любого файла — проверить, есть ли аналог, можно ли переиспользовать компонент, не дублируется ли логика.

Запрещено: временные файлы, дубли компонентов, лишние util-функции, бессмысленные обёртки, мёртвый код. Предпочитать изменение существующего кода созданию нового.

## Безопасность

`Icon.tsx` использует `dangerouslySetInnerHTML` — разметка полностью своя, из `data.ts`. Если появится загрузка SVG от пользователей, прогонять через DOMPurify или парсить пути в структуру.

## Стиль

Цвета — только CSS-переменные (`--bg`, `--fg`, `--muted`, `--line`, `--surface`, `--surface-2`) из `index.css`. Тема переключается через `data-theme` на `<html>`, тёмная также подхватывается из `prefers-color-scheme`. Анимации быстрые и ненавязчивые; `prefers-reduced-motion` уже обработан глобально.
